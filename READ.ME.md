Name: QuizzieMe

QuizieMe will allow users to create virutal flash cards that can be saved for studying purposes. The user will have the option to write flash cards and reveal flash cards. The user can create multiple flash card decks that store several topics for those flash cards. The user can find community decks in the community tab where they can download them and use them for trivia
